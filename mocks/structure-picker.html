Elaborate is a stage

Structure, Polish, Facts and Challenge are checks: they run on a draft, in any order, as often as you like. Elaborate happens once, before there is a draft, and the checks come after it. So the joined pair stays the picker, and when Elaborate is picked the panel shows the stages under the header: Elaborate, Write, Check, the current one lit. Structure has no stages; it starts at Check with its proposal as the first result.

  • 1 · Elaborate. The skeleton beside your notes: the paragraphs the message needs, your fragments placed, what is missing. Nothing written for you. Apply puts your fragments in the editor in that order; Keep mine leaves the notes and runs the checks on them.
  • 2 · Write. The skeleton stays beside the draft as a guide and marks each paragraph written, seeded or empty from the draft alone. The chips are visible but grey: the checks wait for Done. Edits never close the guide.
  • 3 · Check. Done runs Structure, Polish, Facts and Challenge on what you wrote, as for any draft. The structure pass reads the result as a draft, so a message that still has its point buried gets a reorder here.

Why this shape

It keeps the badge meaning what it means today: open the panel. It keeps the picker one row. It makes the difference between the two jobs visible exactly when it matters, in the stage line, and nowhere else. And it never writes a sentence for you: the only text that reaches the editor is your own fragments, moved.

In code

  • Checks gains elaborate (additive), exclusive with structure in the panel. Pass S takes its mode from the checks; the text-based detection from dev build 43 goes.
  • The stage line reads the state that already exists: an open outline is Elaborate, guiding is Write, anything after is Check.
  • Organize gains job and gap lines per paragraph so both modes render through one section component.
  • The guide, the fill check and Done are already in dev build 43.
