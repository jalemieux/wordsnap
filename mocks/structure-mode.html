Structure waiting on you

At the click

Today the badge starts every check at once. With two things the structure pass can do, the badge asks first: Organize keeps every sentence and regroups them; Elaborate lays out the paragraphs a message on this needs, places what you typed, and names what is missing. Both then run the other checks. The choice is made at the moment it matters, on what is actually in the editor, with nothing else on screen yet. Nothing runs until one is clicked; Esc or a click elsewhere closes it and nothing is sent.

After the run

The pane header carries the same two positions, so a wrong pick is one click from the other one; flipping re-runs the pass in the other mode and the checks that depend on it. Per draft, remembered for the session.

One pane, four cases

The pane does not change shape with the input or the mode. Every section is the same four lines: role, one line on the job for the reader, your material that belongs there, and a Missing line when there is a hole. Organize a draft: sentences regrouped, few gaps. Elaborate a draft: the same sentences placed, plus the paragraphs the draft lacks (an ask, a next step by when). Organize an idea: fragments in reading order, honest and thin. Elaborate an idea: the skeleton, with empty slots and what each needs. Apply writes your material in that order and nothing else, in all four.

What changes in code

  • The badge click opens a two-entry menu instead of starting the run; the entry sends the mode with the first snapshot. Auto-analyze mode keeps starting on its own, in Organize.
  • A mode on the pass S request; the prompt gets the two jobs as two branches. The detection that shipped in dev build 43 goes.
  • The schema is already there. Organize gains the same job and gap per paragraph as the skeleton, so both render through one section component.
  • structure/mode (additive) and SessionState.structureMode; flipping in the pane re-runs S.
  • The guide after Apply, the fill check and Done already exist and apply to both.
