# WordSnap

An AI layer that helps you sharpen your own argument before you send it. Not a ghostwriter: a sparring partner that runs three passes over your draft where you already write (Gmail, X, LinkedIn) and leaves your voice alone.

- Clarity and structure: fuzzy thinking, hedges, weak structure.
- Fact check: every checkable claim, with sources and confidence.
- Counterargument: the strongest rebuttal, blind spots, gaps.

## In this repo

- `docs/SPEC.md`: technical spec for the Chrome extension (v0.1). `docs/spec.html` is the same document as a standalone page.
- `mocks/wordsnap-mocks.html`: interactive design mock. Open it in a browser; the top bar switches between the UX variants that were compared.

Status: design and spec. No extension code yet.
